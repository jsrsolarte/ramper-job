# Proposal

## Why

El MVP ya permite ingresar, mantener el perfil y consultar vacantes, pero su interfaz aún tiene una presentación funcional y básica. Darle una identidad visual consistente desde esta etapa hará más clara y confiable la búsqueda diaria, y dejará una base reutilizable para las nuevas fuentes y funciones.

## What Changes

- Definir un sistema visual consistente para ingreso, dashboard y edición del perfil.
- Mejorar la jerarquía de las vacantes: compatibilidad, empresa, ubicación, descripción organizada, razones y enlace original.
- Refinar estados vacíos, avisos, formularios y navegación para que guíen al usuario con claridad.
- Mantener la experiencia adaptable a pantallas pequeñas y las plantillas Django existentes.

## Capabilities

### New Capabilities
- `interfaz-usuario`: presentación visual, navegación y estados de las pantallas privadas del producto.

### Modified Capabilities

## Impact

- Plantillas Django de ingreso, dashboard y perfil.
- Hoja de estilos compartida y estructura de navegación.
- Sin cambios en APIs, modelos de datos, fuentes de vacantes ni proveedor de IA.
